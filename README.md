# 🎓 Plateforme de Délibération Scolaire

Une application web moderne pour la gestion des délibérations scolaires de la 6ème à la Terminale.

## 📋 Description

La Plateforme de Délibération est une solution complète permettant aux établissements scolaires de gérer électroniquement les délibérations des résultats d'élèves. Elle offre une interface intuitive pour les professeurs, directeurs et personnel administratif.

### ✨ Fonctionnalités principales

- **🔐 Authentification sécurisée** : Connexion pour professeurs, directeurs et personnel administratif
- **📊 Tableau de Bord** : Vue d'ensemble avec statistiques en temps réel
- **📚 Gestion des Classes** : De la 6ème à la Terminale
- **📝 Délibération** : Gestion des statuts (Admis, Redouble, Tangent)
- **🎨 Interface intuitive** : Codes couleur pour identification rapide
  - 🟢 Vert : Admis
  - 🔴 Rouge : Redouble
  - 🟠 Orange : Tangent (attention particulière)
- **📈 Rapports et Statistiques** : Visualisation des données
- **💾 Export/Import** : Gestion des données en masse

## 🛠️ Technologies Utilisées

### Frontend
- **React 18** - Framework JavaScript
- **Vite** - Build tool rapide
- **Tailwind CSS** - Framework CSS
- **React Router DOM** - Navigation
- **React Table** - Tableaux dynamiques
- **Recharts** - Graphiques et visualisations
- **Framer Motion** - Animations
- **Axios** - Requêtes HTTP
- **React Hot Toast** - Notifications
